# 공개 프로필 구성

개발 도구와 API 계약을 살펴보는 방문자가 대표 사례의 문제·변경·검증 범위를 첫 화면에서 확인할 수 있게 한다. 하네스, 미술관 계약, 찾았슈 계약 범위 검색, 팀 배포 오류를 먼저 두고 모델 학습·평가는 보조로 둔다. 찾았슈는 공개 재현과 원본의 합성 검색 평가를 구분하고 생성 답변·지급 정확도로 표현하지 않는다.

공개 main에 있는 내용만 설명한다. 팀 작업과 개인 재현을 구분하며 검사 수를 실제 서비스 성과로 바꾸지 않는다. 자세한 실행·설계·한계는 각 저장소로 연결한다. 연락처와 비공개 자료는 복제하지 않는다.

완료 기준: 근거 링크가 익명 요청으로 열리고 최신 CI 수치와 일치한다. 링크 검사 Actions 성공 후 병합한다.
